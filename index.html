웹 서비스 · 예시 프로젝트

Focusboard

문제
할 일이 여러 채널에 흩어져 있으면 작업의 진행 상태와 다음 할 일을 파악하기 어렵습니다.
구현 예시
카드를 상태별로 나누고, 상세 화면에서도 상태를 바꿀 수 있게 구성합니다. 카드와 열의 순서는 별도로 관리해 이동한 카드를 정확한 위치에 저장합니다.
기술 선택
React로 보드와 카드의 표시를 나누고, TypeScript로 카드 상태와 변경에 필요한 값을 정의합니다.

개발 도구 · 예시 프로젝트

Snippet Kit

문제
전에 작성한 코드를 다시 쓰려면 여러 저장소와 메모에서 이름이나 용도를 찾아야 합니다.
구현 예시
코드에 언어와 태그를 지정하고 제목과 본문을 검색할 수 있게 합니다. 검색 결과에서 필요한 코드 조각을 바로 복사합니다.
기술 선택
IndexedDB에 코드를 저장해 브라우저를 다시 열거나 네트워크에 연결되어 있지 않아도 사용할 수 있게 합니다.

개발 도구 · 예시 프로젝트

API Monitor

문제
API의 현재 상태를 확인해도 응답이 언제 느려졌는지, 실패가 반복됐는지 알기 어렵습니다.
구현 예시
응답 코드와 지연 시간을 주기적으로 기록합니다. 최근 응답 시간과 오류가 발생한 시점을 함께 표시해 변화를 추적합니다.
기술 선택
Node.js에서 상태 확인 요청을 보내고, SQLite에 기록을 쌓아 기간과 엔드포인트별로 조회합니다.
